# Health Innovations & Medical Devices Jobs (by major) | ECS 1100

A searchable list of 194 real health innovation and medical device job postings for ECS 1100 students at UT Dallas, organized by Jonsson School major, with the skills that repeat and a saved PDF for every posting.

## Files

- `index.html` is the whole site (data, styles and the built-in PDF viewer are inside it).
- `pdfs/` holds one PDF per posting, named `HI-###_employer_title.pdf`.
- `.nojekyll` tells GitHub Pages to serve the files as they are.

## Publish on GitHub Pages

1. Create a new public repository and upload everything in this folder (including `.nojekyll` and the `pdfs` folder) to the repository root.
2. Go to Settings > Pages, choose "Deploy from a branch", pick `main` and `/ (root)`, then save.
3. The site appears at `https://<your-username>.github.io/<repository-name>/` after a minute or two.

The page also works from any static web server. Opening `index.html` straight from disk may block the PDF viewer in some browsers, so use the hosted link.
